# Pyodide 0.27.2 (core runtime)

Unmodified core files from the official [Pyodide](https://github.com/pyodide/pyodide) 0.27.2 npm package,
licensed under the Mozilla Public License 2.0. They're hosted here so the compiler works even when the
jsDelivr CDN is blocked. Extra packages (numpy, pandas, matplotlib, …) are still downloaded from jsDelivr on demand.
